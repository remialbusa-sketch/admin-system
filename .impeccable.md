# Admin System Design Context

## Design Context

### Users

Field coordinators and operations managers use the board grid during active operational work. They need to scan large record sets, update statuses, assignments, dates, and typed fields quickly, then make confident decisions from the same data.

### Brand Personality

Executive and refined, fast and precise. The interface should feel authoritative enough for leadership review while remaining direct and efficient for high-frequency field coordination.

### Aesthetic Direction

A refined operations instrument: dense but legible, spreadsheet-native in interaction, with deliberate hierarchy and restrained visual accents. Preserve the existing light/dark theme toggle and maintain strong contrast in both modes.

### Design Principles

- Make the grid feel like a working surface, not a decorative data table.
- Prioritize scan speed, keyboard movement, and low-friction cell editing.
- Use restrained executive polish through typography, spacing, and precise status color rather than ornament.
- Keep advanced controls discoverable without crowding the primary record surface.
- Preserve a detailed item drawer for context, validation, and mobile workflows.
